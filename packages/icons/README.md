# @sangyu-ui/icons

Sangyu UI 的 Vue 3 图标组件包。

## 安装

```bash
pnpm add @sangyu-ui/icons
```

项目需要安装 Vue 3.5 或更高版本。

## 使用

```ts
import { SyIcon, SySearch } from '@sangyu-ui/icons';
import '@sangyu-ui/icons/style.css';
```

```vue
<template>
	<SySearch />
	<SyIcon name="search" size="20" color="#1677ff" />
</template>
```
