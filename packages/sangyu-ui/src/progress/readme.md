# Progress 组件设计说明

## 基础需求

1. 支持两种类型：`circle` 和 `line`。
2. 支持是否展示进度信息，默认展示百分比文本。
3. 支持自定义颜色，且兼容系统主题色，如 `primary`、`success`、`warning`、`error`。
4. `line` 类型支持圆角设置，以适配不同风格的条形进度视觉。
5. 支持 `size` 设置，用于控制组件整体厚度或直径。

## 交互与展示建议

- `line` 类型用于内容流中的过程反馈，适合上传、处理队列、安装进度等场景。
- `circle` 类型更适合数据面板、统计卡片、概览区块中的单值进度表达。
- 百分比默认显示，便于用户感知任务接近完成的程度；如果页面信息密度较高，可以关闭展示。
- 当 `percentage` 超出边界时，应自动收敛到 `0 ~ 100`，避免视觉溢出。

## 推荐接口设计

- `percentage`: 当前进度值。
- `type`: 进度条类型，`line | circle`。
- `showInfo`: 是否显示百分比。
- `color`: 进度主色。
- `trackColor`: 轨道底色，可选。
- `size`: 线高或圆形直径。
- `borderRadius`: 线形进度条圆角。
- `customStyle`: 自定义样式扩展。

## 文档建议

- 至少提供基础线形、圆形、自定义颜色尺寸三个示例。
- 文档中明确 `size` 在不同类型下的含义。
- 明确说明 `trackColor` 未设置时会自动生成浅色轨道。

## 测试建议

- 验证 `percentage` 的边界收敛行为。
- 验证 `showInfo` 开关是否正确控制百分比显示。
- 验证 `line` / `circle` 两种类型的渲染结构。
- 验证颜色、圆角和尺寸是否正确反映到 DOM 样式与属性上。
