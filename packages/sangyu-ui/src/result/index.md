# SyResult 结果页

结果组件用于在关键动作完成后，明确告诉用户“发生了什么”“现在处于什么状态”“下一步应该做什么”。它适合支付完成、提交审批、权限拦截、异常页面和局部操作反馈等场景。

## 设计建议

- `success / error / warning / info` 更适合操作完成后的反馈场景。
- `403 / 404 / 500` 更适合页面级状态或大面积空状态提示。
- 默认布局适合独立结果页，`compact` 更适合卡片、弹层和局部信息区域。
- CTA 按钮不要过多，通常 1 个主动作 + 1 个次动作即可，避免用户在结果页再次做复杂决策。
- 当页面需要解释原因、修复建议或附加说明时，可使用默认插槽承载补充信息块。

## API

### 属性

| 属性名      | 类型                                                                     | 说明                                     | 默认值      |
| ----------- | ------------------------------------------------------------------------ | ---------------------------------------- | ----------- |
| status      | `'success' \| 'error' \| 'info' \| 'warning' \| '404' \| '403' \| '500'` | 结果状态                                 | `'info'`    |
| title       | `string`                                                                 | 主标题，不传时根据 `status` 提供默认标题 | `''`        |
| subTitle    | `string`                                                                 | 副标题 / 说明文案                        | `''`        |
| icon        | `string`                                                                 | 自定义图标名称，渲染为 `SyIcon`          | `''`        |
| layout      | `'default' \| 'compact'`                                                 | 布局类型                                 | `'default'` |
| customStyle | `string`                                                                 | 自定义内联样式                           | `''`        |

### 插槽

| 名称     | 说明                                              |
| -------- | ------------------------------------------------- |
| icon     | 自定义顶部图标 / 插画区域，优先级高于 `icon` 属性 |
| title    | 自定义标题内容                                    |
| subTitle | 自定义副标题内容                                  |
| default  | 自定义补充说明区域                                |
| extra    | 自定义操作区，通常放按钮                          |

## 行为说明

- `403 / 404 / 500` 默认会渲染数字状态视觉，而不是普通图标。
- 当同时传入 `icon` 属性和 `icon` 插槽时，优先使用插槽。
- 当未传 `title` 时，组件会根据 `status` 自动补充默认标题。
