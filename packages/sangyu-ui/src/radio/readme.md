# Radio 组件需求分析

## 组件目标

1. 提供单选能力，适用于表单选择、筛选项切换、配置项互斥选择等场景
2. 保持单个组件可独立使用，同时支持通过 group 统一管理选中值
3. 组件风格需要兼顾基础单选样式和按钮式单选样式，便于后续扩展

## 组件组成

1. 父组件为 `sy-radio-group`，用于管理一组选项的选中值
2. 子组件包含 `sy-radio` 和 `sy-radio-button`
3. `sy-radio` 支持脱离 `sy-radio-group` 单独使用
4. `sy-radio-button` 建议依赖 `sy-radio-group` 使用，主要用于按钮化单选场景

## 功能性需求

1. 支持基础单选功能，同一组内任意时刻只能选中一个值
2. 支持通过 `value` 或 `label` 标识当前选项的值，用于和 group 的选中值比对
3. 支持默认选中和受控切换，便于父组件手动管理状态
4. 支持选项变更时触发回调函数，并返回当前选中的值和对应选项信息
5. 支持禁用状态
6. 禁用后不可点击、不可切换、不可触发变更事件
7. 支持文本插槽或属性形式展示选项内容

## Group 需求

1. `sy-radio-group` 负责统一传递当前选中值、禁用状态和变更事件
2. group 内的所有 `sy-radio` 和 `sy-radio-button` 共享同一个选中结果
3. 当点击未选中的选项时，group 更新当前值并通知父级
4. 当点击已选中的选项时，不重复触发变更事件
5. group 可以支持横向和纵向排列，便于表单和列表场景使用

## 样式与形态

1. `sy-radio` 支持圆形和方形两种基础形态
2. `sy-radio-button` 需要具备按钮态样式，选中时有明显的背景、边框或文字高亮变化
3. 支持基础尺寸区分，例如 `small`、`default`、`large`
4. 支持选中、未选中、hover、disabled 四类基础状态样式
5. 选中状态需要有明确视觉反馈，保证可读性和可识别性

## 交互细节

1. 点击单选框本体或文本区域都可以触发选择
2. 键盘交互建议支持 `Tab` 聚焦和 `Space` 触发选择，后续可继续补齐方向键切换能力
3. 当组件处于禁用态时，鼠标样式和视觉反馈需要同步变化
4. group 内切换选项时，需要保证状态更新一致，不出现多个选中项

## 可扩展项

1. 后续可以增加自定义颜色主题
2. 后续可以增加边框风格、按钮圆角、间距等样式配置
3. 后续可以补充表单校验联动能力

## 验收标准

1. 单个 `sy-radio` 可以独立完成选中展示和状态同步
2. `sy-radio-group` 内只能存在一个被选中的子项
3. `sy-radio` 和 `sy-radio-button` 都可以接入 group 使用
4. 点击选项后能正确更新状态并触发回调
5. 禁用状态下不可交互，且样式符合禁用预期
6. 圆形、方形、按钮态三种表现形式都能正常展示
