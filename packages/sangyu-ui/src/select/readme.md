## SySelect 选择器需求文档

1. 组件定位
SySelect 是 Sangyu UI 的基础选择器组件，用于从一组选项中选择单个或多个值。
适用场景：
 - 表单字段选择，例如状态、分类、地区、用户、标签。
 - 筛选条件选择，例如表格筛选、搜索条件、分页每页条数。
 - 大数据选项选择，例如上千至上万条本地选项。
 - 远程搜索选择，例如用户搜索、组织搜索、接口联想。
 - 可创建选项的标签输入场景。

项目里 SyPagination 文档已经提到“每页条数选择器应复用现有 SySelect”，因此 SySelect 应作为基础表单组件优先保证稳定、可组合、性能可控。

2. 参考目标
Ant Design Vue 的大数据 Select 示例重点体现：
 - 大量 options 渲染时仍保持下拉流畅。
 - 下拉列表不应一次性渲染全部 DOM。
 - 搜索、选中、滚动需要在大数据场景下保持可用。
 - API 需要支持简单 options 配置，而不是只依赖手写 option 子节点。
SySelect 不需要完全照搬 AntDV，但建议吸收其核心思路：options 数据驱动 + 虚拟滚动 + 可搜索 + 受控值模型。

3. 设计目标
 - API 风格贴合现有 Sangyu UI：v-model、size、disabled、loading、customStyle、插槽扩展。
 - 默认支持单选，逐步扩展多选、搜索、远程搜索。
 - 大数据场景必须通过虚拟滚动兜底，避免下拉卡顿。
 - 支持键盘操作和基础无障碍语义。
 - 样式使用 --sy-* 主题变量，与 SyInput、SyCheckbox、SyPagination 保持统一。
 - 内部可复用 SyInput 的视觉语言，但交互不应依赖原生 

4. 功能需求  
4.1 基础选择
- 支持 v-model / modelValue。
- 支持单选模式。
- 支持通过 options 传入选项数组。
- 支持点击选择项后自动关闭下拉。
- 支持清空已选值。
- 支持禁用整个组件。
- 支持禁用单个选项。
- 支持 placeholder。
- 支持 loading 状态。
- 支持空数据展示。

## 4. 功能需求

### 4.1 基础选择

1. 支持 `v-model` / `modelValue`。

2. 支持单选模式。

3. 支持通过 `options` 传入选项数组。

4. 支持点击选择项后自动关闭下拉。

5. 支持清空已选值。

6. 支持禁用整个组件。

7. 支持禁用单个选项。

8. 支持 placeholder。

9. 支持 loading 状态。

10. 支持空数据展示。

    ## 4.2 多选模式

    建议第二阶段实现。

    1. `multiple` 开启多选。
    2. 多选时 `modelValue` 为数组。
    3. 已选项以 tag 形式展示。
    4. 支持删除单个 tag。
    5. 支持 `maxTagCount` 控制最多展示数量。
    6. 支持 `max` 限制最多选择数量。
    7. 多选选择后默认不关闭下拉。
    8. 选中项在下拉列表中展示勾选状态。

    ### 4.3 搜索能力

    1. `filterable` 开启搜索。
    2. 单选搜索时，点击选择器后输入框进入可输入状态。
    3. 多选搜索时，输入框嵌入 tag 列表尾部。
    4. 默认按 `label` 本地过滤。
    5. 支持 `filterMethod` 自定义过滤。
    6. 搜索关键字变化时触发 `search` 事件。
    7. 清空搜索词后恢复完整列表。
    8. 选中后是否清空搜索词可通过 `clearSearchOnSelect` 控制。

    ### 4.4 远程搜索

    建议第二阶段或第三阶段实现。

    1. `remote` 开启远程搜索。
    2. `remoteMethod` 接收搜索词，由业务方请求数据。
    3. 远程搜索期间展示 loading。
    4. 远程模式下组件不主动过滤 options。
    5. 支持防抖，建议 `debounce` 默认 `300ms`。
    6. 支持搜索词为空时是否触发远程请求。

### 4.5 大数据与虚拟滚动

这是本组件的重点能力。

1. 当 `virtual` 为 `true` 时启用虚拟滚动。
2. 默认建议开启虚拟滚动。
3. 支持 `itemHeight` 配置单项高度。
4. 支持 `listHeight` 配置下拉列表最大高度。
5. 只渲染可视区域附近的选项。
6. 滚动时根据 `scrollTop` 计算起止渲染索引。
7. 使用上下 padding 或占位块撑开真实滚动高度。
8. 选中项打开下拉时，应自动滚动到可见区域。
9. 搜索过滤后需要重新计算虚拟列表。
10. options 数量较少时也可以使用同一套逻辑，降低分支复杂度。
