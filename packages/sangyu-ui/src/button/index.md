## API

### 属性

| 属性名   | 类型                          | 说明           | 默认值    |
| -------- | ----------------------------- | -------------- | --------- |
| type     | `default`  \|`primary`\|`dashed` | 按钮的各种类型 | `default` |
| size     | `default` \|`small`\|`large`    | 按钮的尺寸     | `default` |
| disabled | `boolean`                     | 禁用           | `false`   |

### 事件

| 事件名 | 说明                 | 类型                         |
| ------ | -------------------- | ---------------------------- |
| click  | 点击按钮后触发的事件 | `(event:MouseEvent) => void` |
